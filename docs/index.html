Full Page Shot

Privacy Policy
No data collected

Last updated: October 2026

Full Page Shot is a browser extension that captures full-page screenshots. This privacy policy explains what data the extension accesses and how it is used.

1. Data collection

Full Page Shot does not collect, store, transmit, or share any personal data. All capture, processing and saving happen locally in your browser. No information is sent to any external server.

2. Permissions and why they are needed

  • debugger — the only way to capture the full page via the Chrome DevTools Protocol (Page.captureScreenshot with captureBeyondViewport). Used solely to take the screenshot.
  • downloads — to save the captured image to your chosen folder.
  • storage — to store your preferences (format, quality, folder, etc.) in storage.sync.
  • clipboardWrite — to copy the captured image to the clipboard when you enable that option.
  • notifications — to notify you when a capture finishes.
  • activeTab — fallback capture for restricted pages (internal pages, PDFs), only when you click the icon on that page.
  • scripting — to inject preparation scripts (cookie dismissal, font loading, repaint) on the page being captured.

The extension does not request host_permissions. The URL and title are read through the DevTools Protocol, not by injecting code into pages.

3. Local storage

Your preferences are stored in chrome.storage.sync (synced across your signed-in browsers by Chrome/Edge). Recent captures (file name, dimensions, timestamp) are stored in chrome.storage.local and never leave your device.

4. Third parties

Full Page Shot does not integrate with any third-party analytics, advertising, or tracking service. It does not use cookies. The only network requests are those made by the web pages you capture (which are independent of this extension).

5. Open source

Full Page Shot is open source under the MIT License. You can audit the code at github.com/AlbertoVasquezR/full-page-shot.

6. Contact

Questions or concerns? Open an issue on GitHub or report a vulnerability via the Security tab.
